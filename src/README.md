# Scientific source and evidence

The directories organize the implementation by scientific responsibility. Use the entry points in `scripts` to check results, run tests, regenerate figures, or replay studies.

| Directory | Contents |
| --- | --- |
| quantum_model | Exact dimer evolution, QPE circuit and forward probabilities |
| known_noise | Known-noise inference and interval-union propagation |
| material_model | Classical susceptibility, fitting and response |
| likelihood_baseline | Conventional likelihood-ratio baseline |
| predictive_inference | Unknown-fraction cross-fit and predictive references |
| continuous_inversion | Nuisance profiling and continuous inversion |
| qpe_study | Comparative studies, observations, results, audits and tests |
| shared_inference | Shared inference kernels |
| manuscript | Plotting helpers and figure-input tables |

Saved observations and results support the article and supplementary material. Dated analysis protocols retain the chronology of study design; computational checks do not constitute independent human verification.
